# HPB

Humanoid Play Basketball：用人类示范重定向到 CASBOT 02，再经强化学习做到实机打篮球。

## 当前阶段

本仓库只有技术设计，不包含机器人模型、仿真环境或训练代码。机器人单臂为 7 自由度。模型文件随后从本地工程放入仓库并用 git 管理；入库之前不训练策略。

- [docs/architecture.md](docs/architecture.md)：接触三层表示、视觉接口、无触觉预判、固定张开手型、从拣球到对抗的技能阶梯。
- [docs/dataset.md](docs/dataset.md)：GVHMR + Holosoma 重定向结果要对齐的样本字段（机器人、球、接触相位、技能名、来源）。

## 数据流

视频或动捕经 GVHMR 得到人体与球的运动，Holosoma 按物体交互重定向到 CASBOT 02。跟踪器沿用已有的 TWIST 结构：教师看未来参考和仿真接触，学生只看本体感觉、当前参考帧和估计的球状态。手部 v1 锁死为张开托球手型，不单独控制手指。

第一项技能是主动拣球（发现地上的球并抱起）。运球、传球、投篮、接球稳定之后，才做 1v1 及以上的技能切换。
